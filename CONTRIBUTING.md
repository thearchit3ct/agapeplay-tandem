# Contribuer

Merci de contribuer à AgapePlay Tandem.

## Avant de proposer une modification

- vérifier qu'une issue ou une discussion n'existe pas déjà ;
- expliquer le problème utilisateur avant de proposer une solution ;
- respecter la confidentialité et la dignité des utilisateurs ;
- ne pas ajouter de promesse médicale, pastorale ou spirituelle excessive.

## Issues

Une issue utile contient :

- le contexte ;
- le type d'utilisateur concerné ;
- le comportement attendu ;
- les limites ou risques identifiés.

## Pull requests

Les pull requests doivent rester petites et expliquer :

- le problème traité ;
- la décision produit ou technique ;
- les tests réalisés ;
- l'impact sur les données personnelles et les rôles d'église.
