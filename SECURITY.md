# Sécurité

AgapePlay Tandem peut manipuler des journaux et conversations sensibles. Merci de ne pas publier de donnée personnelle dans une issue, une pull request ou une discussion publique.

## Signaler une vulnérabilité

Pour une vulnérabilité, utilisez en priorité la fonction **Report a vulnerability** de l'onglet Security du dépôt GitHub afin de créer un rapport privé.

Le rapport devrait contenir :

- une description concise ;
- les étapes de reproduction ;
- l'impact possible ;
- une proposition de correction si elle est connue.

Nous ne demandons pas de preuve de concept destructrice et nous remercions les personnes qui évitent tout accès à des données réelles.

## Règles de sécurité du projet

- aucune donnée réelle dans les fixtures ou captures ;
- aucun journal privé dans les logs ;
- aucune clé secrète dans Git ;
- revue obligatoire des permissions et politiques RLS ;
- revue humaine des changements touchant les conversations, les mineurs ou la modération.
