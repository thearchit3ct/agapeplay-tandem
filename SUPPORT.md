# Support

Avant de poser une question :

1. consulter le [README](README.md) ;
2. consulter la [documentation](docs/) ;
3. vérifier les issues ouvertes et fermées ;
4. ouvrir une discussion ou une issue avec le contexte utile.

Ne publiez jamais d'adresse email, de journal spirituel, de conversation privée ou de capture contenant une donnée personnelle.
