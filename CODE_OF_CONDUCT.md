# Code de conduite

AgapePlay Tandem veut être un espace de travail respectueux, accueillant et responsable.

Nous attendons de chacun :

- respect des personnes, de leurs traditions et de leurs parcours ;
- désaccords argumentés sans attaques personnelles ;
- attention particulière aux sujets de foi, de santé et de vulnérabilité ;
- aucune publication de données privées ;
- signalement de bonne foi des problèmes de sécurité ou de comportement.

Les comportements intimidants, discriminatoires, harcelants ou manipulateurs ne sont pas acceptés. Les responsables du projet peuvent modifier, masquer ou fermer une contribution qui met une personne en danger ou sort du cadre de ce code.

Pour un problème de comportement, ouvrir une demande privée via les moyens indiqués dans [`SECURITY.md`](SECURITY.md) ou contacter les mainteneurs du dépôt.
