# Roadmap proposée

Les dates seront fixées après la phase de découverte. Les étapes sont exprimées en dépendances et résultats vérifiables.

## Phase 0 — Découverte et cadrage

Objectif : confirmer le problème, le vocabulaire et le modèle d'accompagnement.

- 10 à 15 entretiens participants ;
- 5 à 8 entretiens mentors ;
- 3 à 5 entretiens responsables d'église ;
- test de trois positionnements ;
- validation du premier parcours ;
- protocole de sécurité et limites du MVP ;
- décision sur la licence des textes bibliques.

## Phase 1 — Fondations techniques

Objectif : pouvoir livrer une première expérience testable.

- monorepo et CI ;
- applications web et mobile ;
- authentification ;
- schéma de données et RLS ;
- design tokens ;
- catalogue de contenu versionné ;
- instrumentation minimale ;
- environnements de développement et staging.

## Phase 2 — Alpha privée

Objectif : tester le cœur relationnel avec 10 à 20 binômes.

- premier parcours ;
- invitation et acceptation du binôme ;
- séance quotidienne ;
- journal privé ;
- partage explicite ;
- check-in hebdomadaire ;
- blocage et signalement ;
- retours qualitatifs hebdomadaires.

## Phase 3 — Pilote église

Objectif : tester le modèle communautaire avec 2 à 4 églises.

- groupes et cohortes ;
- rôles mentor/responsable ;
- tableau de signaux minimaux ;
- onboarding responsable ;
- export et suppression ;
- rapport d'impact agrégé ;
- formation mentor.

## Phase 4 — Bêta publique

Objectif : ouvrir l'accès avec une base de confiance documentée.

- publication iOS et Android ;
- web public optimisé ;
- support ;
- politique de confidentialité ;
- traitement des demandes de données ;
- localisation anglaise ;
- observabilité et incident response ;
- modèle économique église.

## Phase 5 — Expansion

- parcours familles et jeunes avec gouvernance dédiée ;
- intégration Versets Flash ;
- défis et jeux AgapePlay ;
- compagnon de parcours Alpha et étude d'un partenariat officiel ;
- parcours original Après Alpha ;
- audio et téléchargement enrichi ;
- intégrations calendrier et liens profonds ;
- API partenaires sous revue de sécurité.
